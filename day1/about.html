About QuickNotes

QuickNotes is a simple app for capturing and organizing your ideas. It helps you save important thoughts before they disappear.

How to use QuickNotes

  1. Open QuickNotes.
  2. Type your note in the note box.
  3. Click Add Note to save it.

Features

  • Quickly capture new notes.
  • View all your saved notes.
  • Use keyboard shortcuts to work faster.

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file
